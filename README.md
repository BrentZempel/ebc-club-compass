# EBC Club Compass

Interactive wayfinding pilot for East Bank Club, based on the 2025 Club map brochure.

## Run locally

Download index.html and open it in a browser. All maps and destination data are embedded; no installation, API key, member login, database, or external assets are required.

## Publish with GitHub Pages

In repository Settings > Pages, choose Deploy from a branch, select main and / (root), and save. GitHub displays the published website address once deployment completes.

## Pilot capabilities

- Search 55 numbered listings across four levels by destination or activity.
- Filter by category and floor.
- Highlight destination areas on the original brochure maps.
- Select a starting location, compare levels, enlarge maps, and print a view.
- Hosted links preserve the selected destination and starting point in the URL fragment.

## Content and validation

Names, numbered listings, and map placements follow the 2025 brochure. Current facilities, availability, hours, and routes require EBC staff verification. This is a map orientation pilot, with no live indoor positioning or verified turn-by-turn navigation. Walk routes with staff before adding directions or claims about accessible connections.

## Next steps

Confirm common routes, name elevator and stair banks, add landmark photos, test on member phones, and place location-specific QR codes at confirmed starting points.

## Updating

The published application is index.html. Changes to main will be published automatically after GitHub Pages is configured to deploy from that branch. Keep future work scoped to this repository.
